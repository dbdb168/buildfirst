# Fonts

All three families are under the SIL Open Font License 1.1, which allows bundling them with the kit and embedding them in PDFs and video.

| Family | Files | Source |
|---|---|---|
| Bricolage Grotesque | `BricolageGrotesque-400/600/700/800.ttf` | Google Fonts (Ateliertriay) |
| Newsreader | `Newsreader-400/400i/500/600.ttf` | Google Fonts (Production Type) |
| Inter | `Inter-Regular/Medium/SemiBold/Bold.otf` | rsms.me/inter (Rasmus Andersson) |

Inter is shipped here because macOS doesn't include it. Without it, the PDF tables and labels quietly fall back to another sans serif.
